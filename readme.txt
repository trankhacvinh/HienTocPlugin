Plugin quản lý landing salon, đăng ký hiến tóc và thành viên MyHair.

== Description ==

Mỗi salon có landing và QR riêng. Landing chứa hai tab form hiến tóc/thành viên, form cấu hình được, hỗ trợ ảnh, phân trang và xuất Excel.

== Installation ==

1. Upload ZIP tại Plugins > Add New.
2. Activate.
3. Tạo salon và trang landing mặc định.
4. Cấu hình form và URL OA.
