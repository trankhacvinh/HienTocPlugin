Quản lý salon, QR, đăng ký hiến tóc, trạng thái, tài khoản và báo cáo trong WordPress.

== Description ==

Plugin hỗ trợ trang đăng ký linh hoạt bằng shortcode và tham số ?salon=XXXX. Form được thiết kế mobile-first và tự hiển thị thông tin salon tương ứng.

== Installation ==

1. Upload plugin và kích hoạt.
2. Vào Hiến tóc → Cài đặt để chọn trang đăng ký.
3. Tạo salon và sử dụng QR/đường dẫn do plugin tạo.

== Uninstall ==

Khi xóa plugin, toàn bộ bảng dữ liệu và tùy chọn do plugin tạo sẽ bị xóa. Hãy sao lưu trước.
